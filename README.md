# Attendance
Supports either name or employee number.  
### Sample queries:
1. is KE0557 present?
2. is Bryan present?
3. attendance for January 27, 2026
4. manufacturing headcount
5. latest attendance

# Activity Monitoring
For queries involving customer and model, put 'customer' or 'model' before the proper name. For queries with station, put 'station' after the proper name.  
### Sample queries:
1. what is Marga's cycle time for SOLDERING station?
2. activity summary for customer DENTSPLY on February 4, 2026
3. what is the output for model VPRO2NORDIC?
4. list of operators
5. who is at ASSEMBLY2 station for model TEMPLOGGER?

# Traceability
Supports serial query, WIP, process flow, station details, etc.
### Sample queries:
1. can you give me the wip for templogger as of March 28, 2026?
2. what is the process flow for kontakt nanoirtag?
3. I found a unit with serial K20160890360. Can you tell me what project it came from?
4. give me list of all active projects
