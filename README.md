# Activity Monitoring
Currently does not support employee number.  
For queries involving customer and model, put 'customer' or 'model' before the proper name. For queries with station, put 'station' after the proper name.  
### Sample queries:
1. what is Marga's cycle time for SOLDERING station?
2. activity summary for customer DENTSPLY on February 4, 2026
3. what is the output for model VPRO2NORDIC?


# Attendance
Supports either name or employee number.  
### Sample queries:
1. is KE0557 present?
2. attendance for January 27, 2026
3. manufacturing headcount
